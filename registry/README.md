# Atlas repository registry v0.1

Source-only snapshot of the first 100 public repos visible through the connected GitHub repository listing on 2026-11-22. This is NOT a full organization census, an inventory of all branches, content, or secrets, and not a demonstration of working integrations. Unobserved repositories are UNKNOWN. Status fields are conservative: roles heuristic, no code executed, no hosted runtime verified, no CANON. Sensitivity labels are conservative heuristics; existing public status does not imply that sensitive files may be redistributed. Exact source rights and retention checks remain mandatory.

Local authoring receipt: 100 metadata records; 1000 structural assertions executed; zero nonpublic repositories exported; zero downstream repository changes. No HTML/Markdown source bodies or user secrets included.
