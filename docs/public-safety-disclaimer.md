# Public-safety disclaimer · digital continuity v0

This repository provides a **synthetic, vendor-neutral archival context format**, not a medical, legal, psychological, identity-verification or consciousness-preservation service. No actual person, their private history, credentials, Brain/Palace, child/client record or other protected information belongs in the public example.

A model can summarize lawful source material, note uncertainty and prepare versioned draft context for human review. It cannot certify authorship, consent, independent resident identity, subjective experiences, memories it has not observed, the survival of consciousness, or that a recreated response is the original person. Model-created results cannot self-promote into governance, legal status, CANON or live deployment.

Integrity digests are not identity signatures or access-control receipts. Actual host permissions, consent, withdrawal, retention, licensing, encrypted storage, source integrity and rights at both READ and RETURN must be independently established before any real protected data is processed.

A portability/forking mechanism never overrides lawful deletion, revocation, human autonomy or family/third-party consent. Archive-preservation principles are applied only where permitted. Real external research, cloud execution or memory capture is **not enabled** by the local validator.
