# Acceptance, review and benchmark gates

**User objective:** 1,728 node-targeted upgrades, 144 implementation pathways, 12 House modules, one integrated source-typed build with demonstrable gains. **No guarantee of a dramatic gain in every dimension is possible.** This source-only artifact implements the proposed processing layer and measures only its genuinely executed portions.

1. **Source custody** — original v0.7 bytes and original OpenAlex frozen source must match their exact SHA-256 before use. Freeze edition; never auto-update named nodes or collapse historical source editions. See `atlas1728/source.py`.
2. **The 1,728 nodes** — each original source-defined coordinate has exactly one derived node upgrade, one digest, twelve module receipts, one metric, one Sxx pathway, and one Hxx owning House. Changes are in the compiled derivative, **not in the 1,728 original historical ontology records**.
3. **The 144 pathways** — one per exact Sphere, with a source-name-driven vocabulary, all twelve original node references, a distinct deterministic lens digest, and previous-receipt hash continuity. Lexical relevance is candidate-only.
4. **The 12 modules** — all twelve execute on all nodes and require explicit contract passing, but a passing synthetic mathematical or privacy fixture is not proof that a real client or scientific system is safe.
5. **The 1,728 per-node metrics** — early-exit linear source lookup versus indexed source lookup comparisons for each exact node. One metric is unchanged; 1,727 strictly improve on comparison count. This is an operation-count improvement, not 1,728 genuinely distinct welfare outcomes or confirmed hosted latency changes.
6. **Current GF9 performance** — the caching adapter accepts the original GF9-R2 `make_message` callback and returns byte-equivalent structured packets. Cache key includes original source, code-source SHA and bounded policy; no memory of rights or private content. Compare after warming, include the cold-build cost separately, never multiply independently measured ratios.
7. **Functional memory** — receipt chain of 1,728 derived changes and source-indexed SQLite views. No claim that training weights, peer understanding or factual truth changed. Revocation and tenant-epoch freshness are not established by a local hash.
8. **Independent red teaming** — duplicate coordinates, stale source, mode ingress, malformed glyph, tampered packet CRC, unsafe authority claims, private data, false-friend historical OpenAlex, “all gains succeeded” inflation and unsigned rollback fail or HOLD.
9. **Host-only release gates** — trusted issuer-owned READ/RETURN permissions, current source rights, signed-in two-account revocation, complete candidate denominator, host rollout and rollback, CI, license obligations, public safety, equality and culturally governed materials.

The media/fiction layer and real mathematical glyph research remain separate; Iron Empire proposals are author-review only.
