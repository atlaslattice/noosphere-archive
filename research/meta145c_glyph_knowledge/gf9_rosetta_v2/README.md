## Endpoints and licensing

A true Rosetta protocol must distinguish *shape*, *sound*, *notation*, *phoneme*, *lexeme*, *intention* and *source rights*. The demo has only mathematical referents and candidate semantics. The Sumerian Oracc ATF, Unicode, ISO 15924 and related script sources are **scholarly examples**, not scraped corpora or automatically translated sign data. Tolkien language and script content is **not reproduced**: only the broad idea of deeply developed, beautiful invented-language aesthetics informs original GF9 art direction.

## Run locally

```
PYTHONPATH=. python -m unittest discover -s tests -p 'test_*.py'
PYTHONPATH=. python -O -m unittest discover -s tests -p 'test_*.py'
PYTHONPATH=. python tests/browser_smoke.py           # requires chromium/playwright + private offline viewer
PYTHONPATH=. python run.py phase1                  # optional regeneration from private source
PYTHONPATH=. python run.py phase2                  # optional restart from verified phase1
PYTHONPATH=. python continue_batch.py --batch 2    # requires batch1 and exact journals
```

Existing source files are never changed. Repeat execution requires explicit authorized environment and a persistent, trusted checkpoint; a fresh chat cannot inherit the prior container's files or an authenticated owner identity merely from a URL.
