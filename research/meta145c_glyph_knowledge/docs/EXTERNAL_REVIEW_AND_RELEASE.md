# GF8 release review and external integration gates

**Current state:** built from source-only META145C public package, new GF8 source-only branch candidate, Python stdlib model, local numerical and browser tests. Nothing is hosted or installed as a production ChatGPT plugin.

## Minimum acceptance before connecting to a real Atlas publisher

1. Pin exact GF7 source edition, nominal material table, model revision, and HSN v0.7 digest separately; do not infer that GF7 axes literally are HSN Houses/Spheres/Nodes.
2. Add a trusted publisher-owned READ and RETURN authorization check for any actual source record or resident note, including revocation during asynchronous retrieval. The Python adapter is not a host IAM gate.
3. Run independent free/clamped/suspended-edge finite-element or experimentally calibrated mode solutions before labeling this a *general Chladni physical frequency engine*. Current solver supports a simply supported rectangle only.
4. Perform physical measurement calibration with real plate, dimensions, mounting, drive, damping, controlled frequency sweeps and nodal-image registration. Use held-out modes and negative controls; record raw data, source SHA and units.
5. Check mode-code compatibility, support aliasing/degeneracy, actual resonance width, excitation-node nulls and modal basis truncation; reject mappings where the mode does not exist in the modeled spectrum or is beyond the validity window.
6. Calibrate frequency-to-pattern aliasing and uncertainty rather than assigning a unique semantic word or glyph to every frequency. Identical modes can share frequencies; different plates can show different patterns at the same frequency.
7. Enforce licensing for any Wikipedia, measured image or cultural glyph material. Historical KG8/GLYPHFORGE and fictional Krakoan/Quenya/Sindarin names are distinct legal/source namespaces.
8. Benchmark prompt quality and latency against a **same-GPT** baseline, with held-out question sets, reference answers and review. Record real p50/p95 input retrieval, numerical tools, LLM and postflight times separately; do not multiply unrelated speedup ratios.
9. Do not write to CANON, change permissions, activate agents, or train foundation-model weights through this wrapper. Explicit expert review is required for scientific and constitutional promotions.
